## Задача: структуруємо запис у файл

<h3 class="task">Завдання</h3>

Задана відомість абітурієнтів, які склали вступні іспити в університет. Структура даних про абітурієнтів
представлена у вигляді такого списку:

```python
[
    {
        "name": "Kovalchuk Oleksiy",
        "specialty": 301,
        "math": 175,
        "lang": 180,
        "eng": 155,
    },
    {
        "name": "Ivanchuk Boryslav",
        "specialty": 101,
        "math": 135,
        "lang": 150,
        "eng": 165,
    },
    {
        "name": "Karpenko Dmitro",
        "specialty": 201,
        "math": 155,
        "lang": 175,
        "eng": 185,
    },
]
```

У кожному словнику цього списку записано прізвище абітурієнта &mdash; ключ `name`, код спеціальності, на яку він
вступає, &mdash; ключ `specialty`, і отримані ним бали з окремих дисциплін &mdash; ключі `math` (математика),
`lang` (українська мова) та `eng` (англійська мова).

Розробіть функцію `save_applicant_data(source, output)`, яка зберігатиме указаний список з параметра `source` у
файл з параметра `output`.

Структура файлу, що зберігається, має бути такою. У кожному новому рядку файлу через кому без
пробілів мають бути записані прізвище абітурієнта, код спеціальності, на яку він вступає, і отримані ним бали з окремих
дисциплін.

```
Kovalchuk Oleksiy,301,175,180,155
Ivanchuk Boryslav,101,135,150,165
Karpenko Dmitro,201,155,175,185
```

Вимоги:

- відкрийте файл `output` для запису, використовуючи менеджер контексту `with` і режим `w`;
- запис нового вмісту файлу `output` має бути або за допомогою методу `writelines`, або методом `write`.
