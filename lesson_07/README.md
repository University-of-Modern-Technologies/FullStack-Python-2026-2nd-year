# Заняття 7 — Основи FastAPI

Навчальний проєкт демонструє роботу з **FastAPI** — сучасним веб-фреймворком для створення REST API. Проєкт включає CRUD операції, middleware, валідацію даних, роботу з базою даних через SQLAlchemy та завантаження файлів.

## Залежності

З кореня `lesson_07` (там же лежить `pyproject.toml`):

```powershell
uv sync
```

Пакети вже прописані в проєкті: `fastapi`, `uvicorn`, `sqlalchemy`, `pydantic`.

## Структура проєкту

| Папка/Файл            | Опис                                                                 |
| --------------------- | -------------------------------------------------------------------- |
| `main.py`             | Основний файл застосунку з API endpoints                             |
| `database/db.py`      | Налаштування з'єднання з базою даних (SQLite)                       |
| `database/models.py`  | SQLAlchemy моделі (Cat, Owner)                                      |
| `middlewares/logs.py` | Middleware для логування HTTP запитів                                |
| `validations/schemas.py` | Pydantic схеми для валідації вхідних та вихідних даних          |
| `public/`             | Статичні файли (CSS, зображення) та Jinja2 шаблони                  |
| `uploads/`            | Папка для завантаження файлів                                       |
| `database.db`         | SQLite база даних (створюється автоматично)                         |

## API Endpoints

### Owners
| Метод    | Endpoint               | Опис                                    |
| -------- | ---------------------- | --------------------------------------- |
| GET      | `/api/owners`          | Отримати список всіх власників         |
| GET      | `/api/owners/{id}`     | Отримати власника за ID                 |
| POST     | `/api/owners`          | Створити нового власника               |
| PUT      | `/api/owners/{id}`     | Оновити дані власника                  |
| DELETE   | `/api/owners/{id}`     | Видалити власника                      |

### Cats
| Метод    | Endpoint               | Опис                                    |
| -------- | ---------------------- | --------------------------------------- |
| GET      | `/api/cats`            | Отримати список всіх котів             |
| GET      | `/api/cats/{id}`       | Отримати кота за ID                    |
| POST     | `/api/cats`            | Створити нового кота                   |
| PUT      | `/api/cats/{id}`       | Оновити дані кота                      |
| DELETE   | `/api/cats/{id}`       | Видалити кота                          |

### Інші
| Метод    | Endpoint               | Опис                                    |
| -------- | ---------------------- | --------------------------------------- |
| GET      | `/`                    | Головна сторінка (HTML шаблон)          |
| POST     | `/upload_file`         | Завантаження файлу (обмеження 1MB)      |
| GET      | `/api/healthchecker`   | Перевірка з'єднання з базою даних      |

## Особливості реалізації

### Middleware
- `LogRequestMiddleware` логує всі HTTP запити та відповіді
- Додає заголовок `X-Response-Time` з часом обробки запиту

### Валідація даних
- Використання Pydantic схем (`CatSchema`, `OwnerSchema`)
- Автоматична валідація вхідних даних
- `response_model` для валідації вихідних даних

### Робота з БД
- SQLAlchemy ORM для роботи з SQLite
- Dependency Injection для отримання сесії БД (`get_db`)
- CRUD операції через SQLAlchemy сесії

### Завантаження файлів
- Обмеження розміру файлу: 1 MB
- Автоматичне створення папки `uploads`
- Перевірка розміру під час завантаження

### Шаблони та статичні файли
- Jinja2 для рендерингу HTML шаблонів
- StaticFiles для обслуговування CSS та зображень

## Запуск застосунку

```powershell
uv run uvicorn main:app --reload
```

Після запуску:
- API доступно за адресою: http://127.0.0.1:8000
- Документація Swagger UI: http://127.0.0.1:8000/docs
- Документація ReDoc: http://127.0.0.1:8000/redoc

## Приклад запиту (cURL)

Створення нового кота:
```bash
curl -X POST "http://127.0.0.1:8000/api/cats" \
  -H "Content-Type: application/json" \
  -d '{"nick": "Murzik", "age": 3, "vaccinated": true}'
```

Отримання всіх котів:
```bash
curl "http://127.0.0.1:8000/api/cats"
```
